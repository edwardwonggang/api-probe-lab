# API Probe Lab 宽松解析测试集
#
# 这是自动化测试与人工复制测试共用的单一文本。
# 所有 Key 都是虚构值，不包含真实凭据。
# <empty> 表示该字段预期为空。

=== 01_same_line_unlabeled | 单行：URL 和无字段 Key ===
EXPECT_BASE_URL=https://api.example.com
EXPECT_API_KEY=vendor_key-1234567890abcdef
EXPECT_DECODED=false
--- INPUT ---
https://api.example.com/v1 vendor_key-1234567890abcdef
--- END ---
